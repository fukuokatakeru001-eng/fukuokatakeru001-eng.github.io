auto-post Privacy Policy

Effective: 2026-11-10 · Home

Who uses this app

auto-post is used only by its owner, for the owner's own accounts: the YouTube channels "AIに全投げ研究所" and "Old Genius, New Tools", and the owner's own X account. It has no other users and does not collect data from anyone else. auto-post uses YouTube API Services.

What Google user data it accesses

  • YouTube upload (https://www.googleapis.com/auth/youtube.upload): to upload the owner's own videos to the owner's own channel, scheduled to be published at the planned time, or published immediately if that time is very close or has just passed.
  • YouTube read-only (https://www.googleapis.com/auth/youtube.readonly): before each upload, to read the authorized channel's ID and name and confirm it is the intended channel; afterwards, to read the publishing status and view count of the videos it uploaded.

The videos are read from the owner's own Google Drive folder, which is shared with the tool's own service account (this does not use the owner's Google sign-in).

How the data is used and stored

  • The data is used only to upload and schedule the owner's videos and to record whether they were published and how many views they have.
  • The owner's private Google Sheet receives the video URL, the publishing status, the view count, and short notes that can include the channel name (and, if the wrong channel was authorized, that channel's name and ID).
  • The same kinds of information (channel name, video URL, view count, status) also appear in the run logs of the owner's private GitHub repository.
  • The OAuth refresh token is stored only as an encrypted secret in the owner's private GitHub repository. It is masked in the run logs and never written to the sheet.
  • Downloaded video files are deleted from the job's temporary storage as soon as the upload finishes or fails.
  • auto-post has no website for users, and it does not use cookies or store anything on visitors' devices. This website itself does not use cookies or analytics.

Sharing

The data is not sold, not shared with other people, not used for advertising, and not used to train AI models. auto-post's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

  • Access can be revoked at any time at https://myaccount.google.com/permissions.
  • If access is revoked, the owner deletes the YouTube data kept by auto-post (the channel names and view counts in the sheet, the related run logs in the private GitHub repository, and the stored token) within 30 days. Deletion requests are handled within 7 days.
  • Uploaded videos can be managed or deleted in YouTube Studio.

See also the YouTube Terms of Service and the Google Privacy Policy.

Contact

Questions or requests: open an issue at https://github.com/fukuokatakeru001-eng/fukuokatakeru001-eng.github.io/issues.

日本語（上と同じ中身）

使う人

auto-post を使うのは持ち主だけです。持ち主のアカウント（YouTube の「AIに全投げ研究所」「Old Genius, New Tools」と、持ち主の X のアカウント）のためだけに使います。ほかの利用者はおらず、ほかの人のデータは集めません。auto-post は YouTube API Services を使います。

使う Google のデータ

  • YouTube のアップロード（https://www.googleapis.com/auth/youtube.upload）：持ち主の動画を持ち主のチャンネルに上げるため。決めた時刻に公開する予約で上げ、その時刻がすぐ近いか少し過ぎていれば、すぐ公開で上げます。
  • YouTube の読み取り（https://www.googleapis.com/auth/youtube.readonly）：上げる前に、許可したチャンネルの ID と名前を読み、決めたチャンネルと同じかを確かめるため。上げたあと、公開されたかと見られた数を読むため。

動画は、持ち主の Google Drive のフォルダ（この道具のサービスアカウントに共有したもの）から読みます（持ち主の Google のログインは使いません）。

使い方としまい方

  • 動画を上げて予約すること、公開されたかと見られた数を記録することだけに使います。
  • 持ち主の非公開の Google スプレッドシートに、動画の URL・公開の状態・見られた数と、チャンネル名が入ることのある短いメモを書きます（違うチャンネルを許可していたときは、そのチャンネルの名前と ID も）。
  • 同じ種類の情報（チャンネル名・動画の URL・見られた数・状態）は、持ち主の非公開の GitHub のリポジトリの実行ログにも出ます。
  • 許可のトークンは、持ち主の非公開の GitHub のリポジトリに、暗号化された Secret としてだけ保存します。実行ログでは隠し、表には書きません。
  • ダウンロードした動画のファイルは、上げ終わったとき（失敗したときも）すぐ消します。
  • auto-post に利用者向けのサイトは無く、cookie も使わず、端末に何も置きません。このサイトも cookie やアクセス解析を使いません。

共有

データを売ったり、ほかの人に渡したり、広告や AI の学習に使ったりはしません。Google の API から受け取った情報の扱いは、Google API Services User Data Policy（Limited Use の決まりを含む）に従います。

保存の期間と削除

  • https://myaccount.google.com/permissions でいつでも許可を取り消せます。
  • 許可が取り消されたら、auto-post が持っている YouTube のデータ（表のチャンネル名と見られた数、非公開の GitHub のリポジトリにある関係する実行ログ、保存したトークン）を、持ち主が30日以内に消します。削除の依頼には7日以内に対応します。
  • 上げた動画は YouTube Studio で管理・削除できます。

YouTube 利用規約と Google プライバシーポリシーも参照してください。
