auto-post

Last updated: 2026-11-10

auto-post is a private, internal tool. The owner of this site built it and runs it only for the owner's own accounts: the YouTube channels "AIに全投げ研究所" (Japanese) and "Old Genius, New Tools" (English), and the owner's own X account.

The owner writes a schedule in a private Google Sheet. Once an hour, a job in a private GitHub repository reads the sheet and checks each row.

  • YouTube (the part that uses Google sign-in): it uploads the owner's own video from the owner's own Google Drive to the owner's own channel, scheduled to be published at the planned time (or published immediately if that time is very close or has just passed). Later it checks whether the video was published and reads its view count.
  • X: it posts the owner's own text, images and short videos to the owner's own X account. This part does not use any Google user data.

auto-post has no public sign-up, no user interface and no other users. No other person or channel uses it.

Privacy Policy

日本語

auto-post は、このサイトの持ち主が、自分のアカウント（YouTube の日本語チャンネル「AIに全投げ研究所」と英語チャンネル「Old Genius, New Tools」、自分の X のアカウント）のためだけに作って動かしている、非公開の道具です。

持ち主が非公開の Google スプレッドシートに予定を書くと、非公開の GitHub のリポジトリのジョブが1時間ごとにそれを読み、行を検査します。

  • YouTube（Google のログインを使う部分）：持ち主の Google Drive にある持ち主の動画を、持ち主のチャンネルに、決めた時刻に公開する予約で上げます（その時刻がすぐ近いか、少し過ぎていれば、すぐ公開で上げます）。そのあと、公開されたかと見られた数を確かめます。
  • X：持ち主の文章・画像・短い動画を、持ち主の X のアカウントに投稿します。この部分は Google のユーザーのデータを使いません。

登録の画面も、ほかの利用者もありません。
